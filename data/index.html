The data files each lesson reads, so you can run the lesson's code yourself. Click a file to download it. Save it where the lesson's code looks for it: most lessons read from a folder called data next to the notebook, so pd.read_csv("data/penguins.csv") reads penguins.csv from that folder.

The data for the tutorials and assignments is already in their folders on JupyterHub; you do not need to download anything for those.

The data sets appear here as each week opens.
